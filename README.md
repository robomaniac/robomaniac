## Selected projects

### [TLA2528 Arduino Library](https://github.com/robomaniac/TLA2528_Arduino_Library)

An Arduino C++ library I developed for the TLA2528 ADC/GPIO device. It provides analog input and digital I/O control, with example sketches and hardware photos.

### [Robotics Drone Gate](https://github.com/robomaniac/robotics-drone-gate)

A Bluetooth-controlled moving gate I built for indoor FPV drone racing. The project combines servo-control firmware, a mobile interface, electronics, and 3D-printed mechanical parts. This is a past prototype built around the Simblee platform.

### [LED Curve Studio](https://github.com/robomaniac/led-curve-studio)

A browser tool for designing LED animations on project photos and exporting GIFs or Arduino sketches. Built with AI assistance from a Clicks interface reference, then extended with editable LED placement, project saving, and Arduino integration. The repository documents the original inspiration and my additions.

Direct browser flashing remains experimental.

**[Try the live editor](https://robomaniac.github.io/led-curve-studio/)**
